## 💎 Features

* 🎛️ Advanced Music Controls (Button Interface)
* 📥 Song Request Channel
* 🕒 24/7 Playback Mode
* 📻 Radio Streaming Support
* 🎚️ Playlist Editor & Custom Filters
* 🌐 Multi-Language Support (6+ Languages)
* ⚙️ Slash Commands Enabled
* 💽 Playlist Management System
* 🌟 Premium System (Optional)
* 📂 Upload & Play Audio Files
* ⏱️ Cooldown System
* 🌐 Shard Support for Large Servers
* 🔁 Auto-Reconnect / Auto Pause & Resume
* 🔍 Auto-Complete Search
* 🔧 Lavalink Auto-Fix via [lavalink.darrennathanael.com](https://lavalink.darrennathanael.com/NoSSL/lavalink-without-ssl)
